# 🎯 ResumeX AI

### Your Personal Career Intelligence Platform

ResumeX AI is a resume analysis application designed to help job seekers understand their resume-job compatibility, identify skill gaps and improve their career readiness.

## ✨ Features

- Resume PDF and DOCX Upload
- Job Description Matching
- Resume Match Score
- Missing Skills Detection
- Interactive Analytics Dashboard
- Recruiter Feedback
- Career Assistant Chatbot
- Downloadable Analysis Report

## 🛠️ Tech Stack

- Python
- Streamlit
- Scikit-learn
- Plotly
- Pandas
- PyMuPDF
- NLP

## ⚙️ Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Install dependencies:

```bash
pip install streamlit pymupdf python-docx scikit-learn pandas plotly
```

Run the application:

```bash
streamlit run app.py
```
